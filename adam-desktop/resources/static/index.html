02 / ALLOW LAPTOP CONTROL

Make the connection yours

Connect ADAM above, then allow it to use the laptop actions you have enabled.

Voice commands need this return connection to your PC. Allow laptop control saves the PC address, port and key on ADAM, so it can work even when automatic discovery is blocked. Keep ADAM and this PC on the same network and allow the PC app through Windows Firewall on your trusted network.

Manual pairing

If guided pairing is unavailable, set LAPTOP_AGENT_IP to this PC’s local address, LAPTOP_AGENT_PORT to the displayed port, and LAPTOP_AGENT_TOKEN to the laptop key in your Pi’s .env, then restart ADAM. These laptop credentials are separate from ADAM’s SYNC_TOKEN.

This key allows ADAM to run enabled laptop actions. Share it only with your own ADAM.
