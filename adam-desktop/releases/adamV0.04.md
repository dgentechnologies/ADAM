# ADAM Desktop 0.04

Download [adamV0.04.exe](adamV0.04.exe) and its [checksum](adamV0.04.exe.sha256).

- Windows x64; unsigned; built with Windows CPython 3.11.9 and PyInstaller 6.16.0 under Wine.
- SHA-256: `593aa5fdac1b2cc3638e11dac7933d27cb5fb695b7f25863058c702506cefd14`.
- Requires Microsoft Edge WebView2 Runtime and supported Windows/.NET runtime.

Recreates ADAM with an oval head, silver rim and horizontal eyes using CSS; adds an
unclipped vector wordmark and a shared ambient gradient. Adds authenticated relay
of signed Pi execution evidence to the trusted Firebase function, with retry-safe
paging and account/device fencing.

Use the matching Pi code and complete physical-key registration and Firebase
rollout. The executable alone does not upgrade the robot or deploy cloud services.
See [rollout and remaining gates](../../docs/PI_FIREBASE_V004_ROLLOUT.md).
Native Windows/hardware acceptance and live Firebase deployment are outstanding.
